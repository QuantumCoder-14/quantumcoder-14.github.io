SiteRakshak

An on-device defence layer for the browser: anti-malware, anti-phishing, fraud and misinformation detection that runs entirely in the tab.

flagship · v16

One suite, three shields.

javascript · manifest v3 · chrome & edge · source-available

The core is SiteArmor: a heuristic engine that scores pages and downloads before you trust them. FactCheck is the optional second module, wiring free public APIs (Google Fact Check Tools, Wikipedia, WHO, NASA) into a local credibility score. A third civic module is in the repo. No backend is required for any protection feature — nothing leaves the browser unless you opt in.

read the source install guide
what it actually detects
  • 153 heuristic rules — tech-support scams, digital-arrest fraud, KYC expiry, wallet drainers, job-fee scams
  • Download scanning — 16 known malware hashes plus obfuscation-decode passes for base64 / UTF-16LE / hex droppers
  • Archive bombs — ratio and chain rules, zip-slip, encrypted-archive escalation
  • CDN integrity — SHA-256 baselines for 18 library releases; tampered scripts get blocked
  • Fingerprinting — hooks Canvas, WebGL, AudioContext, WebRTC and font probing
  • Quishing — decodes QR codes on the page and flags the link behind them
  • Dark patterns — fake countdowns, false scarcity, confirmshaming
  • Prompt injection — invisible instructions aimed at AI agents; visible text is never flagged

about

Teenager with a keyboard,
too many ideas.

I'm a student. Most of what I know came from breaking things — a motor driver, a bootloader, a badly written extension permission. The pattern that stuck: build the thing that runs without anyone's permission, on hardware you own, with no server to go down.

That's why the projects here lean local-first. SiteRakshak scores threats inside the browser because asking a server is a privacy decision you didn't agree to. The same instinct shows up in the embedded work: sense, decide, act, without a round trip.

Currently going deeper on computer vision and embedded AI, and looking for people to build with.
