what I have shipped

Things that exist, and that I can point at

Every line below is verifiable from a public repository. No prizes, no invented credentials — just work you can open, run, and disagree with.

01
ScamCheck — an offline scam-message checker
21 rule groups across nine categories, built for the fraud Indian users actually receive: fake CBI calls, KYC phishing, customs-fee parcels, task-job scams. 41 tests, including a no-false-positive check so a genuine OTP message is not flagged.
02
QR Studio — six kinds of QR code, generated locally
UPI payment intents, Wi-Fi credentials, links with trackers stripped, contact cards, calendar events, free text. 41 tests plus every code decoded back with OpenCV to prove the payload survives.
03
CrapClean 2.0 — rescued a broken Windows cleanup script
The original batch file deleted the temp folders, wiped Prefetch, and called deltree, which has not existed since XP. Rewritten as a windowed tool with preview, logging and an undo. The original is preserved untouched as v1.0.
04
downsort — sort Downloads, with an undo
Ten categories, duplicate detection by SHA-256, and a log that replays backwards. 26 tests, including one asserting two runs in a day cannot destroy the first one's result.
05
Four sharp command-line utilities
passgen (CSPRNG passwords and passphrases), urlclean (70 tracking parameters), sizewise (what is eating your disk), imgpress (shrink images without touching the originals). 50 tests between them, no dependencies except Pillow.
06
249 automated assertions, all passing from fresh clones
Not "it worked when I opened it". Every project ships a test suite; the counts above come from cloning each repository and running its suite as the README documents.
