# quantumcoder-14.github.io

The source of **[quantumcoder-14.github.io](https://quantumcoder-14.github.io)** — a single
`index.html`, no build step, no framework, no dependencies to install.

## Editing it

Open `index.html`, change the text, commit. Pages rebuilds in about a minute.

Everything lives in that one file: the styles, the markup and about six lines of
JavaScript that fill in the copyright year. The only remote request is Google Fonts,
and the font stack has system fallbacks, so the page still reads fine without it.

## What is on it

- Who I am and what I build: robotics, embedded systems, applied AI
- SiteRakshak as featured work, with what it actually detects
- The other repositories, with forks labelled as forks
- The toolchain, and how to reach me

## Deliberate choices

- **No trackers, no analytics, no cookies.** Nothing to consent to, nothing to leak.
- **Dark by default**, light theme if the visitor's OS asks for it.
- **No JavaScript framework.** The page is text and CSS; it loads in one request.
